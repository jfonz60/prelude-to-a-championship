PRELUDE TO A CHAMPIONSHIP — MOBILE EVENT HUB V2

This version contains the corrected 12-team schedule and all 12 uploaded team rosters.

FREE PUBLISHING — GITHUB PAGES
1. Create/sign in to a free GitHub account.
2. Create a new PUBLIC repository named: prelude-to-a-championship
3. Upload every file from this folder (not the enclosing folder itself).
4. In the repository, choose Settings > Pages.
5. Under Build and deployment choose: Deploy from a branch.
6. Choose branch: main and folder: / (root), then Save.
7. Wait a minute or two. GitHub will show your public HTTPS site address.
8. Send that final web address to ChatGPT. A permanent QR code can then be created for fans.

UPDATING LATER
The player data lives in data.js. The QR code does not need to change if you keep the same published URL.

NOTE
Roster information is reproduced from the school-supplied files. Marion County's source roster did not include player positions, so those cells display a dash.
